# First App Revenue — First Customer Segment

## Decision
**First customer segment:** 소규모 시설 유지보수 / 현장 점검 팀

구체적으로는:
- 빌딩 / 상가 / 다세대 주택 관리 보조
- 시설 유지보수 담당자
- 점검 결과를 사진과 메모로 남겨야 하는 소규모 팀

## Why this segment first
- 반복 점검이 있어서 사용 빈도가 높다
- 사진 + 짧은 메모 + 상태 태그 + PDF 보고서 흐름과 딱 맞는다
- 결과물을 바로 공유해야 해서 수익화 근거가 분명하다
- 범용 현장관리 플랫폼보다 훨씬 작은 MVP로 시작할 수 있다
- 기존 enterprise tool보다 더 단순한 흐름을 만들기 쉽다

## What this segment needs most
1. 현장에서 빠르게 사진을 찍는다
2. 사진별 짧은 메모를 붙인다
3. 상태 태그를 남긴다
4. 템플릿을 고른다
5. PDF 보고서를 바로 공유한다

## Why not start broader
- 부동산 관리 전체로 가면 범위가 커진다
- 보험 피해 기록은 문서 타입이 더 다양하다
- 소규모 건설/수리는 점검보다 작업관리로 확장되기 쉽다
- 홈 인스펙션은 소비자형 UX가 섞여 MVP가 흐려질 수 있다

## Product implications
- 홈 화면 문구는 “새 보고서 시작”보다 “새 점검 보고서”에 더 가깝게 갈 수 있다
- 템플릿은 2~3개만 먼저 둔다
- 상태 태그는 아주 단순하게 시작한다
- OCR / AI 요약 / 협업 기능은 v1에서 뺀다

## Next action
이 세그먼트를 기준으로 첫 3개 화면의 문구와 기본 상태를 더 좁힌다.
