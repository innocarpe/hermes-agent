# First App Revenue Playbook — Competitor Benchmark

## 목적
현재 제안한 `사진 → 보고서 / 문서화 앱`이 실제 고객이 있는 시장인지, 그리고 어디에 끼어들 수 있는지 경쟁 앱 기준으로 확인한다.

이 문서는 `docs/hq/first-app-strategy-principles.md`의 **시장/경쟁 판단**을 보강하는 보조 문서다.

## 결론
- **실제 고객 있음**: yes
- **경쟁 앱 있음**: 매우 많음
- **즉시 차별화 가능성**: 좁은 워크플로로만 가능
- **권장 포지션**: 현장 사진 + 짧은 메모 + 상태 태그 + PDF 보고서

## 핵심 비교 대상 3개

| 앱 | 공식 링크 | 핵심 포지션 | 강점 | 우리와의 관계 |
|---|---|---|---|---|
| SafetyCulture iAuditor | https://safetyculture.com/iauditor | inspection / checklist / report | 시장 대표주자, 보고서/체크리스트 기대치 확립 | 직접 경쟁, 정면승부 금지 |
| Fulcrum | https://www.fulcrumapp.com/ | field data collection platform | 현장 입력 / 템플릿 / 데이터 수집 강함 | 더 넓은 플랫폼, 우리는 더 좁아야 함 |
| GoCanvas | https://www.gocanvas.com/ | mobile field work management | 워크플로 디지털화, 양식/리포트 | 기능 범위 넓음, 우리는 단일 흐름만 |

## 3개 앱 공통 신호
- 현장 입력은 사진만이 아니라 **증빙 + 상태 + 구조화된 결과물**로 이어진다
- 고객은 단순 메모보다 **공유 가능한 문서**를 원한다
- 템플릿과 반복 양식은 강한 가치다
- B2B/SMB 워크플로는 구독 또는 seat 기반 과금과 잘 맞는다

## 각 앱이 보여주는 시장 사실

### 1) SafetyCulture iAuditor
- https://safetyculture.com/iauditor
- inspection / audit / checklist 시장이 이미 크다
- 사용자는 현장 점검을 문서로 남겨야 한다
- 우리의 시사점:
  - 보고서 형식은 이미 익숙하다
  - 그러나 우리가 iAuditor처럼 되면 너무 커진다
  - MVP는 체크리스트 플랫폼이 아니라 **사진 기반 보고서 생성기**여야 한다

### 2) Fulcrum
- https://www.fulcrumapp.com/
- field process and data collection 플랫폼
- 사용자는 데이터를 모으고 정리하고 내보내야 한다
- 우리의 시사점:
  - 템플릿 기반 수집은 시장성이 있다
  - 하지만 플랫폼화되면 범위가 급증한다
  - 우리는 데이터 수집 플랫폼이 아니라 **보고서 산출물 중심**이어야 한다

### 3) GoCanvas
- https://www.gocanvas.com/
- mobile field work management / workflow digitization
- 사용자는 현장 업무를 디지털 폼으로 바꾼다
- 우리의 시사점:
  - 폼/워크플로를 모두 잡으면 너무 넓다
  - 우리는 폼 빌더가 아니라 **사진 + 메모 + PDF** 흐름만 가져간다

## 시장 해석
### 이 시장은 새 시장이 아니다
- 이미 유저가 있고
- 이미 경쟁 앱이 있고
- 이미 과금 구조가 있다

### 그래서 필요한 것은
- 더 큰 앱이 아니라
- 더 좁은 앱
- 더 빠른 앱
- 더 명확한 출력물을 만드는 앱

## MVP 포지션
**권장 MVP wedge:**
> 사진을 찍고, 짧은 메모와 상태를 붙이고, 템플릿을 골라, 바로 공유 가능한 PDF 보고서를 만드는 앱

## 왜 이 wedge가 유효한가
- 경쟁 앱들이 이미 시장을 증명했다
- 그러나 대부분은 범위가 넓다
- 우리 MVP는 단일 업무 흐름으로 더 작게 만들 수 있다
- 사용자는 “사진 → 보고서”를 바로 이해한다

## 리스크
- 범용 문서 스캐너처럼 보이면 차별화가 약해짐
- inspection SaaS처럼 커지면 1개월 MVP를 넘김
- AI를 앞세우면 기능이 넓어질 위험이 큼
