# Discord YouTube 채널 라우팅 체크리스트

이 문서는 YouTube/콘텐츠 벤치마크를 `04-채널`에서 실제 라우팅 판단으로 바꾸기 위한 실행 체크리스트다.

## 1) 먼저 분류하기
아래 중 무엇인가?
- `news`
- `analysis`
- `how-to`
- `expert`
- `archive/repackaging`

## 2) 라벨 점검
- 채널 라벨이 실제 시장을 정확히 말하는가?
- 같은 라벨의 대형 경쟁자가 이미 포화 상태인가?
- 더 넓거나 더 구체적인 클러스터로 다시 정의할 수 있는가?

## 3) 리스크 점검
- 의료, 법률, 재무, 범죄처럼 고위험 주제인가?
- source quality를 증명할 수 있는가?
- disclosure가 필요한가?
- review ownership이 명확한가?

## 4) 운영성 점검
- 반복 제작 가능한 포맷인가?
- 소수 인원으로 유지 가능한가?
- 설명만 길고 실행 가능한 판단이 없는가?
- `launch` 이후 운영 기준이 남는가?

## 5) 최종 routing
아래 하나로 끝낸다.
- `launch`
- `reframe`
- `gate`
- `drop`

## 6) 결과 기록
- 판단이 끝나면 decision log에 남긴다.
- 고위험 주제는 왜 gate 했는지 한 줄로 남긴다.
- reframe이면 무엇을 바꿨는지 한 줄로 남긴다.
- launch이면 어떤 포맷이 반복 가능한지 한 줄로 남긴다.

## 판정 예시
- `AI 뉴스` → `reframe` or `gate`
- `의학/건강` → `gate`
- `세계사 타임라인` → `launch` 가능
- `절세/세무` → `gate` 후 launch 검토

## 사용 원칙
- 이 체크리스트는 콘텐츠 초안이 아니라 **채널 위치 결정**용이다.
- 내용이 아니라 **구조와 리스크**를 먼저 본다.
- 판단 결과는 decision log에 남긴다.
