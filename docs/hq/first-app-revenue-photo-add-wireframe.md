# First App Revenue Playbook — Photo Add Wireframe

> 참고: 이 문서는 `docs/hq/first-app-strategy-principles.md`와 `docs/hq/first-app-doc-map.md`를 기준으로 읽는 보조 문서다.

## 목적
사용자가 보고서에 들어갈 사진을 가장 빠르게 추가하게 만든다.

## 원칙
- 사진 추가는 복잡하면 안 된다
- 촬영과 업로드를 같은 진입점으로 묶는다
- 여러 장을 연속으로 넣는 흐름이 쉬워야 한다
- 사진이 들어가면 바로 다음 행동이 보여야 한다

## 추천 화면 구조

```text
┌──────────────────────────────────┐
│  새 점검 보고서 > 사진 추가          │
│                                  │
│  [ 카메라로 찍기 ]               │
│  [ 갤러리에서 선택 ]             │
│                                  │
│  추가된 사진 3장                 │
│  ┌────┐ ┌────┐ ┌────┐           │
│  │ 1  │ │ 2  │ │ 3  │           │
│  └────┘ └────┘ └────┘           │
│                                  │
│  각 사진에 메모 추가 >           │
└──────────────────────────────────┘
```

## 화면에서 보여줄 것
- 카메라 진입 버튼
- 갤러리 진입 버튼
- 추가된 사진 미리보기
- 다음 행동 버튼

## 화면에서 숨길 것
- 앨범 정렬 옵션
- 태그 관리
- 편집 툴 전부
- OCR / AI 분석
- 공유 옵션

## 중요한 UX 포인트
- 촬영 후 바로 목록에 추가돼야 한다
- 사진 삭제는 각 썸네일에서 즉시 가능해야 한다
- 사진 순서를 바꾸는 기능은 나중에 붙여도 된다
- 사용자는 먼저 “사진이 잘 들어갔다”는 확신을 가져야 한다

## 다음 화면으로 이어지는 흐름
1. 카메라 / 갤러리에서 사진 추가
2. 사진 썸네일 확인
3. 각 사진 메모 입력
4. 템플릿 선택으로 이동

## 판단 기준
이 화면을 본 사용자가 아래를 즉시 이해해야 한다.
- 어떻게 사진을 넣는지
- 몇 장이 들어갔는지
- 다음에 무엇을 해야 하는지

## 다음 액션
- 사진별 메모 입력 화면을 만든다
- 그 다음 템플릿 선택 화면으로 연결한다
