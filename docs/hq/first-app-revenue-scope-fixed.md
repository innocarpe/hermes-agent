# First App Revenue Playbook — Scope Fixed

## Decision
**Primary target customer:** 소규모 시설 유지보수 / 현장 점검 팀

구체적으로는:
- 빌딩 / 상가 / 다세대 주택 관리 보조
- 시설 유지보수 담당자
- 점검 결과를 사진과 메모로 남겨야 하는 소규모 팀

## Why this target
- 사진과 메모가 곧바로 보고서가 되는 흐름과 잘 맞는다
- 반복 사용 가능성이 높다
- 결과물을 PDF로 바로 공유해야 하는 필요가 강하다
- 글로벌 시장에서 동일한 워크플로가 반복된다
- 1개월 MVP 범위로 자르기 쉽다
- **반복 비용이 큰 문제**라서 유료 전환 근거를 만들기 쉽다
- **지불 주체가 비교적 분명한 직무형 문제**다
- **소수 인력으로 운영 가능한 MVP**로 자르기 쉽다

## Primary use case
1. 현장에서 사진을 찍는다
2. 짧은 메모와 상태를 붙인다
3. 템플릿을 선택한다
4. PDF 보고서를 내보내고 공유한다

## What this is not
- 범용 노트 앱이 아니다
- 협업형 현장관리 플랫폼이 아니다
- 복잡한 폼 빌더가 아니다
- OCR 중심 앱이 아니다
- AI 자동 작성이 핵심인 앱이 아니다

## MVP success criteria
- 첫 보고서를 30초 안에 만들 수 있어야 한다
- 결과물이 업무 문서처럼 보여야 한다
- 사용자가 공유할 이유를 바로 이해해야 한다
- 반복 사용 시나리오가 보여야 한다

## Secondary audiences
- 홈 인스펙션
- 보험 / 피해 기록
- 소규모 건설 / 수리 현장

## HQ note
이 결정은 "가장 큰 시장"을 고른 것이 아니라, **가장 작은 MVP로 가장 명확한 문제를 푸는 시장**을 고른 것이다.
