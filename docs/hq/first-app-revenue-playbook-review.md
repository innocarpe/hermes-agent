# First App Revenue Playbook — Evidence Review

> 아카이브 메모: 이 리뷰는 초기 가설 검토용이다. 최신 판단 기준은 `docs/hq/first-app-strategy-principles.md`를 먼저 보고, 문서 순서는 `docs/hq/first-app-doc-map.md`를 따른다.

## 목적
이 문서는 개발자용 “첫 앱 매출 플레이북” 아이디어를 **사업 전략 관점에서 검토**하고, TemperStone HQ 안에서 재사용 가능한 형태로 정리한 리뷰 문서다.

## 한줄 결론
- **학습용 실험**으로는 좋다.
- **의미 있는 사업 전략**으로는 약하다.
- 핵심 문제는 **범용 유틸리티 앱의 포화도**와 **광고 수익만으로는 얇은 경제성**이다.
- 자세한 판정 기준은 `docs/hq/first-app-strategy-principles.md`를 따른다.

---

## 판정

| 항목 | 판단 | 메모 |
|---|---|---|
| 실행 용이성 | 높음 | 혼자서 빠르게 출시 실험 가능 |
| 학습 가치 | 매우 높음 | 배포, 스토어, 광고, 분석을 한 번에 경험 가능 |
| 시장성 | 낮음 | 범용 유틸리티 앱은 경쟁이 매우 심함 |
| 수익화 실현성 | 낮음 | 광고 단독 모델은 규모가 필요함 |
| 차별화 가능성 | 조건부 | 니치 문제로 좁혀야 가능 |
| 비용 대비 결과 | 보통 이하 | 실험은 가능하나 ROI 기대는 낮음 |

## 메모에서 수정이 필요한 가정

### 1) CPI 50원
- 글로벌 유료 설치 기준으로는 **매우 낙관적**이다.
- 저가 국가 트래픽에서는 일부 가능해도, 일반적인 기대값으로 두기 어렵다.

### 2) 18만원으로 2000 다운로드
- 계산상 설치당 약 90원 수준인데, 이것도 공격적이다.
- 현실적으로는 CPI가 조금만 올라가도 다운로드 수가 크게 줄어든다.

### 3) 2000 다운로드에서 5천~1만원 광고수익
- 아예 불가능한 수치는 아니지만,
- **사업적으로 의미 있는 수익**이라기보다는 **학습용 실험 결과**에 가깝다.

### 4) “광고만으로 벌기”
- 광고는 수익화의 시작점이지, 대체로 완성형 전략이 아니다.
- 반복 사용, 높은 세션 수, 높은 유지율이 없으면 수익이 얇다.

## 현실적인 재작성

### 원래 메시지
> 직장 다니면서 할 수 있는, 개발자의 첫 앱 매출 플레이북

### 현실 버전
> 직장 다니면서 할 수 있는, 개발자의 첫 앱 **검증** 플레이북

### 목표 재정의
- 큰 매출을 내는 것보다,
- **앱 출시 → 유입 → 사용 → 수익화 → 분석**의 한 사이클을 완주하는 것
- 그리고 **실제로 사람들이 반복해서 쓸 문제인지** 확인하는 것

---

## 현실적인 실행 원칙

1. **범용 앱보다 니치 앱**
   - “또 하나의 계산기/클리너/변환기”는 피한다.
   - 특정 직군, 특정 상황, 특정 반복 업무를 겨냥한다.

2. **입력 → 처리 → 결과 구조**
   - 입력이 명확하고 결과가 명확한 앱이 좋다.
   - 복잡한 플랫폼형 서비스는 초기 단계에서 제외한다.

3. **고비용 API 지양**
   - 서버 비용과 호출 비용이 커지면 실험이 금방 무거워진다.

4. **로그인 제거 또는 최소화**
   - 첫 사용 장벽을 낮추고, 온보딩을 단순하게 만든다.

5. **광고만 고집하지 않기**
   - Pro unlock, 1회 결제, 니치 구독 가능성을 열어둔다.

## 추천 평가 기준

### 이 앱이 가치 있으려면
- 사용자가 문제를 10초 안에 이해할 수 있어야 함
- 1회 사용이 아니라 반복 사용 가능성이 있어야 함
- ASO로 노릴 키워드가 있어야 함
- 광고 외 수익화도 열려 있어야 함
- 유지보수 비용이 낮아야 함

### 위험 신호
- 시장 설명이 길어야만 이해되는 앱
- 비슷한 앱이 이미 너무 많은 앱
- 세션이 짧고 재방문이 거의 없는 앱
- 광고를 많이 넣어야만 수익이 나오는 앱
- 고비용 API를 써야만 성립하는 앱

## 추천 앱 방향 10개

아래는 “범용 광고앱”보다 가능성이 높은 방향들이다.

### 1) 특정 직군용 업무 도구
- 예: 현장 체크리스트, 기록 보조, 견적/정산 보조
- 장점: 반복 사용 가능, 유료 전환 가능
- 리스크: 니치 조사 필요

### 2) 사진 → 텍스트/요약/보고서 변환기
- 예: 작업 사진을 구조화된 기록으로 변환
- 장점: 결과가 명확하고 가치 전달이 쉬움
- 리스크: OCR/AI 비용 설계 필요

### 3) 메모 → 할 일/주간 정리 도구
- 예: 러프한 메모를 정리된 액션 아이템으로 바꿈
- 장점: 개인 생산성 니치와 궁합 좋음
- 리스크: 차별화 필요

### 4) 반복 입력 자동화 툴
- 예: 같은 형식의 보고/기록을 빠르게 만드는 도구
- 장점: 업무 맥락에서 지불 의사 생김
- 리스크: 타깃이 너무 넓어지면 약해짐

### 5) 한국어 맥락 특화 앱
- 예: 국내 업무, 생활, 행정 흐름에 맞춘 보조도구
- 장점: 글로벌 복제와의 차별화 가능
- 리스크: 배포/ASO 전략이 필요

### 6) 습관/루틴 추적 앱
- 예: 매일/매주 기록하고 리포트 받는 앱
- 장점: 재방문이 생기기 쉬움
- 리스크: 유지율이 핵심

### 7) 좁은 계산/변환 도구
- 예: 특정 업종 전용 단위변환, 비용계산, 규격계산
- 장점: 검색 의도가 명확함
- 리스크: 시장이 작을 수 있음

### 8) 문서화 보조 앱
- 예: 스크린샷/메모/녹음에서 문서 초안 생성
- 장점: 시간 절약 가치가 큼
- 리스크: 경쟁이 빠름

### 9) 개인 업무 로그 앱
- 예: 일간 작업, 시간, 상태, 메모를 빠르게 기록
- 장점: 반복 사용과 리포트가 자연스러움
- 리스크: UX가 중요

### 10) 매우 좁은 B2B 마이크로툴
- 예: 소규모 팀/개인사업자용 보조 도구
- 장점: 광고보다 직접 결제와 잘 맞음
- 리스크: 고객 발견이 필요함

## TemperStone HQ 관점의 추천 결론

### 이 플랜을 어떻게 볼 것인가
- **좋은 학습 프로젝트**
- **약한 사업 전략**
- **니치 문제 해결형으로 바뀌면 유의미해질 수 있음**

### 다음 액션
1. 범용 앱 아이디어를 버리고, 니치 문제 3개만 뽑는다.
2. 각 아이디어를 같은 카드 포맷으로 정리한다.
3. 수익화보다 먼저 **반복 사용 가능성**을 검증한다.
4. 광고는 보조 수단으로 두고, Pro unlock 가능성을 열어둔다.
