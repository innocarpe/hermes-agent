# First App Revenue — Benchmark Summary

> 아카이브 메모: 이 파일은 `docs/hq/first-app-revenue-competitor-comparison.md`와 `docs/hq/first-app-revenue-repeated-complaints.md`의 요약본이다. 새 판단은 `docs/hq/first-app-strategy-principles.md`를 먼저 보고, 상세 근거는 두 원본 문서를 본다.

## 목적
경쟁 앱 비교와 반복 불만 패턴을 한 파일에서 빨리 보기 위한 요약 메모.

## 핵심 결론
- 고객은 실제로 있다.
- 경쟁도 강하다.
- 그래서 범용 플랫폼이 아니라 **좁은 photo-to-report 워크플로**로 가야 한다.
- 가장 가까운 대체재는 CompanyCam이고, 가장 큰 플랫폼 경쟁자는 SafetyCulture / Fulcrum / GoCanvas / TrueContext다.

## 추천 방향
> 현장 사진 + 짧은 메모 + 상태 태그 + 템플릿 기반 PDF 보고서

## 경쟁 비교 요약
- SafetyCulture: inspection + corrective action + reports + tasks + comms
- Fulcrum: field data collection + GIS + offline maps + integrations
- GoCanvas: digital forms + image/video capture + offline + GPS + barcode
- TrueContext: mobile forms + workflow + integrations + analytics
- CompanyCam: photo-first jobsite docs + timelines + annotations + report builder

## 반복 불만 요약
- 종이/스프레드시트가 느리다
- 폼/워크플로가 복잡하다
- 사진과 메모가 흩어진다
- 현장과 사무실 사이 handoff가 느리다
- 플랫폼이 너무 무겁다
- 보고서를 빠르게 만들기 어렵다
- 오프라인이 중요하다
- 설치 후 바로 이해돼야 한다

## 다음 액션
- 첫 타깃 고객 1개를 고정
- 그 타깃에 맞는 템플릿 2~3개만 설계
- 리뷰/벤치마크를 그 타깃으로 재수집
