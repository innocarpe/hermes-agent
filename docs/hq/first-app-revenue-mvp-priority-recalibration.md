# First App Revenue Playbook — MVP Priority Recalibration

## 목적
시장조사와 경쟁 벤치마크를 반영해, 지금 당장 먼저 밀어야 할 MVP 우선순위를 다시 정리한다.

이 문서는 `docs/hq/first-app-strategy-principles.md`를 기준으로 **우선순위 재조정**만 담당한다.

## 결론
### 1순위: 사진 → 보고서 / 문서화 앱
- 이유: 가장 명확한 제품 메시지
- 결과물(PDF)이 분명함
- 글로벌-first로 설명이 쉽다
- 1개월 MVP로 자르기 쉽다

### 2순위: Shift handover / daily operations logbook
- 이유: 시장 균형은 매우 좋음
- 반복 사용성과 B2B 가치는 강함
- 하지만 positioning이 조금 더 추상적이다
- 현장 문서화 앱보다 메시지가 덜 직관적일 수 있다

### 3순위: Receipt / invoice capture → expense export
- 이유: 결제 의사가 강하다
- 다만 OCR / 회계 / export 요구가 빨리 커진다
- MVP가 간단해 보여도 통합이 커질 수 있다

### 4순위: Fleet / equipment inspection notes
- 이유: 반복 점검 수요가 분명하다
- 하지만 도메인 특화가 강해서 초기 타깃이 좁아진다

## 왜 순위를 이렇게 두는가

### 사진 → 보고서 / 문서화 앱이 1순위인 이유
- 사용자가 바로 이해한다
- 산출물이 명확하다
- 경쟁 앱 대비 기능 범위를 좁히기 쉽다
- 글로벌 표현이 가능하다
- 실제로는 현장 문서화의 가장 작은 단위다

### Shift handover가 강한데도 2순위인 이유
- 시장성은 좋다
- 반복 사용도 좋다
- 그러나 사용자에게 처음 설명할 때 "누가 왜 쓰는지"를 더 길게 설명해야 한다
- 제품 메시지가 사진 보고서보다 덜 즉시적이다

## 재조정 원칙
- **시장성**만 보지 않는다
- **설명 가능성**과 **MVP 단순성**을 같이 본다
- 1개월 MVP에서는 “가장 큰 시장”보다 “가장 짧게 결과를 만드는 흐름”이 중요하다

## 최종 선택 유지 여부
**유지:** 사진 → 보고서 / 문서화 앱

## 다음 액션
