# Global-First App Recommendation

## 기준
이 문서는 다음 조건을 동시에 만족하는 앱 방향을 고른다.

- **글로벌 시장이 이미 존재할 것**
- **유저 그룹이 명확할 것**
- **벤치마크할 수 있는 기존 앱이 있을 것**
- **MVP를 1개월 안에 만들 수 있을 것**
- **개발 난이도가 과도하지 않을 것**
- **반복 비용이 큰 문제일 것**
- **누가 돈을 내는지 분명할 것**
- **소수 인력으로 운영 가능할 것**

## 결론
### 1순위 추천
> **사진 → 보고서 / 문서화 앱**

이 방향이 가장 잘 맞는 이유는:
- 시장이 존재한다.
- 사용자가 분명하다.
- 기존 앱과 비교가 쉽다.
- 기능을 아주 좁게 잡으면 1개월 MVP가 가능하다.
- 국가 의존성이 높지 않아 global-first가 자연스럽다.

### TemperStone 판단 기준
이 방향은 다음 기준에서도 통과한다.
- 사용자가 사진/문서를 남길 때마다 반복 비용이 생긴다.
- 결과물의 구매자 또는 지불 주체가 비교적 분명하다.
- 입력 → 처리 → 출력 흐름이 짧아서 운영이 단순하다.
- 1개월 MVP로 범위를 자르기 쉽다.

---

## 왜 이게 현장 점검 앱보다 더 맞는가

### 현장 점검 앱
- 시장은 확실히 있다.
- 그러나 기능 범위가 쉽게 커진다.
- 오프라인, 폼 빌더, 팀 협업, PDF 리포트, 권한 관리까지 바로 필요해질 수 있다.
- 그래서 1개월 안에 깔끔한 MVP를 만들기 어렵다.

### 사진 → 보고서 / 문서화 앱
- 입력/처리/출력이 더 단순하다.
- 핵심 흐름이 짧다.
- MVP가 작다.
- 1개월 안에 출시 가능한 범위로 자르기 쉽다.

---

## 추천 MVP 정의

> 사용자가 사진을 찍고, 짧은 메모를 붙이고, 템플릿을 선택해서, 바로 공유 가능한 PDF 보고서를 만드는 앱

### 최소 기능
- 사진 촬영 / 업로드
- 사진별 메모 입력
- 상태 태그
- 템플릿 선택
- PDF 생성
- 링크 공유 / 내보내기

### 나중에 붙일 기능
- OCR
- AI 요약
- 팀 공유
- 프로젝트별 정리
- 저장소 동기화

## 타깃 유저 예시
- 홈 인스펙션 / 부동산 점검
- 시설 유지보수
- 현장 작업 기록
- 보험/피해 기록
- 간단한 감사/점검 보고가 필요한 개인/소규모 팀

## 최종 판단
- **시장 있음**: yes
- **유저 있음**: yes
- **글로벌 가능**: yes
- **1개월 MVP 가능**: yes
- **개발 난이도 과도하지 않음**: yes

따라서, 현재 조건에서 가장 맞는 방향은 **사진 → 보고서 / 문서화 앱**이다.
